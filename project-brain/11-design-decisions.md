# Design Decisions

## Hero

Decision:
Use a bold community image with a concise value proposition rather than a collage.

Reason:
The original website lacked immediate clarity and emotional impact.

---

## CTA Hierarchy

Primary:
Join the Mission

Secondary:
Donate

Reason:
The organization's long-term success depends on growing its community, not only receiving donations.

---

## Impact

Decision:
Place measurable outcomes before asking for donations.

Reason:
Trust should be established before requesting support.

# Global Design Decisions

## Homepage Purpose

The homepage should tell the organization's story.

It is not intended to fully satisfy every audience.

Instead, it introduces each audience and guides visitors toward dedicated interior pages.

---

## CTA Hierarchy

Primary CTA

- Join the Mission

Secondary CTAs

- Donate
- Volunteer
- Access Resources

This hierarchy is intentional.

The homepage should prioritize long-term engagement before transactional actions.

---

## Impact

The homepage contains a summary of impact.

The dedicated Impact page contains detailed stories, metrics, and outcomes.

---

## Existing Website

The current website should always be reviewed before redesign.

Preserve:

- valuable content
- recognizable messaging
- brand equity

Improve:

- hierarchy
- accessibility
- storytelling
- visual design
- conversion
